# Concise print method for cbc_design objects

Concise print method for cbc_design objects

## Usage

``` r
# S3 method for class 'cbc_design'
print(x, ...)
```

## Arguments

- x:

  A cbc_design object

- ...:

  Additional arguments passed to print

## Value

Returns the input `cbc_design` object invisibly (class: c("cbc_design",
"data.frame")). This function is called for its side effect of printing
a concise summary of the CBC design to the console, including design
method, structure, D-error metrics, profile usage, and a preview of the
design data.
