# Convert dummy-coded CBC data back to categorical format

This function is depreciated. Use
[`cbc_encode()`](https://jhelvy.github.io/cbcTools/reference/cbc_encode.md)
instead

## Usage

``` r
cbc_decode(data)
```

## Arguments

- data:

  A `cbc_design` or `cbc_choices` object with dummy-coded categorical
  variables

## Value

The input object with categorical variables restored to their original
format
